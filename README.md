# Finance Tracker

Консольное приложение для учёта личных финансов на Python: доходы и расходы, категории, месячные лимиты, отчёты и экспорт в CSV. Работает на стандартной библиотеке Python, ничего устанавливать не нужно.

> A command-line personal finance tracker in Python (SQLite, argparse, unit tests). Standard library only.

## Возможности

- Добавление доходов и расходов с категорией, заметкой и датой
- Месячные лимиты по категориям и предупреждение о превышении
- Отчёт за месяц или за всё время: итоги и расходы по категориям с долями
- Экспорт всех операций в CSV (открывается в Excel)
- Данные хранятся в базе SQLite (`~/.finance_tracker/finance.db`)

## Установка и запуск

Нужен Python 3.8 или новее.

```bash
git clone https://github.com/<jaiganabeka>/finance-tracker.git
cd finance-tracker
python -m finance_tracker --help
```

## Примеры

```bash
python -m finance_tracker add income 350000 -c Зарплата -d 2026-10-01 -n "Оклад за сентябрь"
python -m finance_tracker add expense 45000 -c Еда -d 2026-10-02
python -m finance_tracker add expense 18500.50 -c Транспорт -d 2026-10-03
python -m finance_tracker add расход 92000 -c Еда -d 2026-10-04
python -m finance_tracker add expense 30000 -c Развлечения -d 2026-10-04

python -m finance_tracker budget set Еда 100000
python -m finance_tracker budget set Развлечения 40000

python -m finance_tracker list -m 2026-10
python -m finance_tracker report -m 2026-10
python -m finance_tracker export operations.csv
```

Тип операции можно писать по-английски (`income`, `expense`) или по-русски (`доход`, `расход`).

   4  2026-10-04  расход  Еда                    -92 000.00 тг

## Команды

| Команда | Что делает |
|---|---|
| `add <income\|expense> <сумма> [-c категория] [-n заметка] [-d дата]` | добавить операцию |
| `list [-m ГГГГ-ММ]` | список операций |
| `delete <id>` | удалить операцию |
| `report [-m ГГГГ-ММ] [--all]` | отчёт (по умолчанию за текущий месяц) |
| `budget set <категория> <сумма>` / `budget list` | месячные лимиты |
| `export <файл.csv>` | выгрузка в CSV |

## Как устроено

```
finance_tracker/
  money.py     # разбор и форматирование сумм и дат
  storage.py   # работа с SQLite (операции, итоги, лимиты)
  report.py    # построение текстового отчёта
  cli.py       # аргументы командной строки (argparse)
tests/         # 17 unit-тестов (unittest)
```

Технические решения:

- **Суммы хранятся целыми числами** в тиынах (1 тг = 100 тиын), а не во `float`, чтобы не было ошибок округления вида `0.1 + 0.2 != 0.3`.
- **SQL-запросы параметризованные** (`?`), без подстановки строк, поэтому нет риска SQL-инъекций.
- В базе стоят ограничения `CHECK` (сумма больше нуля, тип только `income`/`expense`), чтобы некорректные данные не попали в таблицу.
- Названия категорий нормализуются: «еда» и «Еда» считаются одной категорией.

## Ограничения и планы

- Одна валюта (тенге), без конвертации.
- Лимиты месячные и одинаковые для всех месяцев.
- Планы: графики (matplotlib), импорт из CSV банковской выписки, веб-интерфейс на Flask или FastAPI.
